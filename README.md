# 🔐 Password Generator in C++

Простой генератор паролей на C++, который создаёт случайные пароли с настраиваемыми параметрами.

---

## 📋 Описание

Программа генерирует случайный пароль на основе выбранных пользователем параметров: длина пароля, использование заглавных букв, цифр и специальных символов.

---

## ⚙️ Возможности

- Настройка длины пароля
- Включение/выключение заглавных букв (A-Z)
- Включение/выключение цифр (0-9)
- Включение/выключение специальных символов (!@#$%^&*...)
- Случайная генерация на основе текущего времени

---

## 🚀 Запуск

### Требования
- Компилятор g++ (или любой другой C++ компилятор)

### Компиляция
```bash
g++ Password_generator.cpp -o password
```

### Запуск
```bash
./password
```
